### 🏏 IPL Score Prediction Using Random Forest

**Tech:** Python · Flask · Random Forest Regressor · Scikit-learn ·
Pandas · HTML · CSS · jQuery

-   Built a Random Forest regression model to predict IPL first-innings
    scores.
-   Achieved an **R² score of 0.914** and **MAE of 5.84 runs**.
-   Performed data preprocessing, feature engineering, and
    hyperparameter tuning.
-   Reduced the model artifact size from **485 MB to 34.5 MB** and
    integrated it into a Flask application for predictions.

🔗 **Live Demo:** [IPL Score
Predictor](https://ipl-score-predictor-j564.onrender.com/)\

[IPL-score-Predictor](https://github.com/bhuprndra/IPL-score-Predictor)
